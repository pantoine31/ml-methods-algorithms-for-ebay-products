# ml-methods-algorithms-for-ebay-products
Comparative study of classical Machine Learning algorithms on real-world data. Regression (Ridge, SGD) and classification (LogisticRegression, LinearSVC, KNN) on eBay Auctions (~296k records) and CIFAR-10 image dataset. Built with scikit-learn pipelines, PCA dimensionality reduction, and reproducible train/test splits.
